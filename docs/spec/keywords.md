# Keywords

via defines keywords in a liberal and strong manner. It does not have any pseudo-keywords. This is to ensure minimal amount of syntactical ambiguity exposed to the end user.

## List of keywords

- `var`
- `mut`
- `fn`
- `match`
- `while`
- `whilex`
- `for`
- `if`
- `ifx`
- `in`
- `as`
- `else`
- `do`
- `return`
- `raise`
- `spawn`
- `import`
- `struct`
- `self`
- `Self`
- `enum`
- `use`
- `none`
- `true`
- `false`
- `bool`
- `int`
- `float`
- `string`
